# סרטון תדמית — Petra

`petra-promo.mp4` — 80 שניות, 1920×1080, 30fps, ללא סאונד. בנוי מימין לשמאל (טקסט מימין, המערכת משמאל).

## מבנה
| זמן | סצנה |
|---|---|
| 0–13.5 | פתיח, הבעיות, לוגו |
| 13.5–18.5 | דשבורד |
| 18.5–27.5 | קביעת תורים אונליין: `/book/[slug]` אמיתי מהנייד עד "ההזמנה אושרה" |
| 27.5–35.5 | תזכורות וואטסאפ: הטקסט המדויק מ-`reminder-service.ts` ומתג "תזכורות אוטומטיות לתורים" |
| 35.5–47.5 | חוזים: "שלח חוזה לחתימה", חתימה ב-`/sign/[token]` בנייד, סטטוס "נחתם" בתיק הלקוח |
| 47.5–57.5 | פנסיון: מפת חדרים ולוח יומי |
| 57.5–69.5 | סוכן AI ("לראשונה בישראל"), תשובות לפי פלט אמיתי של `get_morning_briefing` |
| 69.5–80 | נתונים וסיום עם הכותרת מדף הנחיתה |

עיצוב נקי בכוונה: בלי אימוג׳ים, בלי תגיות ורשימות וי, בלי גרדיאנטים. האימוג׳ים שנשארו (בהודעת הוואטסאפ ובמסך "ההזמנה אושרה") הם מה שהמערכת עצמה שולחת ומציגה.

## מקור
- כל מסכי המערכת ב-`shots/` צולמו מהאפליקציה האמיתית (build production מקומי) עם נתוני דמו.
- `capture/` — הסקריפטים ששימשו לצילום: `promo-seed*.js` (נתוני דמו ל-DB מקומי), `flows.py` / `shoot.py` (Playwright), `contract.html` (החוזה לדוגמה). הנתיבים בהם מוחלטים — לעדכן לפני הרצה.
- חלון הצ'אט של ה-AI ובועת ה-WhatsApp הם הדמיה (אין צילום של אפליקציה חיצונית); התוכן בהם אמיתי.

## עריכה ורינדור מחדש
טקסטים ותזמונים ב-`promo.html` (לכל סצנה `--s` = התחלה, `--d` = משך; לכל אלמנט `--o` = השהייה בתוך הסצנה).

```bash
pip install playwright imageio-ffmpeg
python3 render.py stills 25 45 65   # צילומי בדיקה
python3 render.py video out.mp4     # רינדור מלא
```
