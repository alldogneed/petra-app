# סרטון תדמית — Petra

`petra-promo.mp4` — 84 שניות, 1920×1080, 30fps, ללא סאונד. בנוי מימין לשמאל (טקסט מימין, המערכת משמאל).

## מבנה
| זמן | סצנה |
|---|---|
| 0–12 | פתיח + הבעיות (תורים בטלפון, חוזים על נייר, פנסיון על לוח מחיק…) |
| 12–21 | "הכירו את פטרה" + דשבורד |
| 21–30 | קביעת תורים אונליין — `/book/[slug]` אמיתי מהנייד עד "ההזמנה אושרה" |
| 30–38 | תזכורות WhatsApp — הטקסט המדויק מ-`reminder-service.ts` + מתג "תזכורות אוטומטיות לתורים" |
| 38–50 | החתמה על חוזים — "שלח חוזה לחתימה" → `/sign/[token]` בנייד → "החוזה נחתם בהצלחה" → סטטוס "נחתם" בתיק הלקוח |
| 50–60 | פנסיון — מפת חדרים + לוח יומי (האכלות) |
| 60–72 | סוכן AI — "לראשונה בישראל"; התשובות מבוססות על פלט אמיתי של `get_morning_briefing` מ-MCP |
| 72–84 | נתונים (130+ / 5,000+ / 98%) + CTA |

## מקור
- כל מסכי המערכת ב-`shots/` צולמו מהאפליקציה האמיתית (build production מקומי) עם נתוני דמו.
- `capture/` — הסקריפטים ששימשו לצילום: `promo-seed*.js` (נתוני דמו ל-DB מקומי), `flows.py` / `shoot.py` (Playwright), `contract.html` (החוזה לדוגמה). הנתיבים בהם מוחלטים — לעדכן לפני הרצה.
- חלון הצ'אט של ה-AI ובועת ה-WhatsApp הם הדמיה (אין צילום של אפליקציה חיצונית); התוכן בהם אמיתי.

## עריכה ורינדור מחדש
טקסטים ותזמונים ב-`promo.html` (לכל סצנה `--s` = התחלה, `--d` = משך; לכל אלמנט `--o` = השהייה בתוך הסצנה).

```bash
pip install playwright imageio-ffmpeg
python3 render.py stills 25 45 65   # צילומי בדיקה
python3 render.py video out.mp4     # רינדור מלא
```
