# Petra video production

## Quick start — new video
1. **Verify claims** (Explore agent) → **script table** (time | narration | on screen) → owner approves.
2. **Screens**: background general-purpose agent captures real app screens (§3).
3. **Voice**: copy `marketing/reel-boarding/` → `marketing/<name>/`, edit `LINES` in `voice.py`, run `python3 voice.py continuous` until every line is 1.00 (§4).
4. **Music**: owner generates in Gemini (prompt template §5) → `python3 .claude/skills/petra-video/scripts/music_check.py track.mp3` → use `track-instrumental.wav`.
5. **Build**: edit `SUBS` + the scene blocks in `build.py build_html()`, `build.py html`, check `build.py stills …`, send `build.py preview 18`, then `build.py video` (§6).
6. **QA**: `python3 .claude/skills/petra-video/scripts/qa_video.py --video … --scenes …` (or `promo` / `reel`) → fix → `SendUserFile` → commit + push (§7).

## Owner preferences (Or) — follow unless told otherwise
- Female voice **`coral`**, natural Israeli Hebrew, "a WhatsApp voice message to a friend" — never announcer/sales/"AI slop".
- **Music at a constant level — never duck under the voice** (rejected explicitly). Clarity comes from voice processing + a constant EQ dip + a lower constant music gain.
- Music must be **purely instrumental** — he hears any vocal chop. Always run `music_check.py`.
- **On-screen text = narration, word for word.** No on-screen claims that aren't said.
- Petra logo everywhere: corner logo on app screens, big logo after the hook, logo at the end.
- CTA: reels "דברו איתנו בוואטסאפ" + 054-256-0964; promo petra-app.com + "מתחילים בחינם".
- Real app screens only; every feature the narration names must be visible.
- He listens critically: sentence endings, breaths, mismatches. Send a preview early; report honestly what is still imperfect.

## Defaults
| Item | Value |
|---|---|
| TTS | `gpt-audio-1.5` (chat completions, audio out), voice `coral`, `voice.NATURAL` system prompt |
| Take strategy | whole script as one continuous take, ≥4 takes pooled, best per line |
| Pass rule | line exact in 2 transcriptions (`gpt-4o-transcribe`); borderline lines → average of 4 |
| Scene timing | `LEAD 0.2` + clip + `TAIL 0.2` (reel); promo `LEAD 0.4`/`TAIL 0.6`; scenes only lengthen |
| Voice chain | highpass 90 → acompressor (thr -22, 3:1, makeup 2) → gain → EQ +3dB @3.2k |
| Music | constant gain -11…-12 dB, EQ -3…-5 dB @2.5k, instrumental stem |
| Loudness | -14 LUFS (reel); promo -15 (voice -2 dB relative to music, owner request) |
| Video | 30 fps, x264 crf 18; reel 1080×1920, promo 1920×1080 |

## Workflow

### 1. Verify every claim against the code
Explore agent: map the module (exact Hebrew UI labels, routes, file paths), mark EXISTS / PARTIAL / MISSING. Never script partial/missing features (e.g. boarding: no photo updates to owners; no alert when incompatible dogs share a yard — only behaviour warnings in the check-in dialog). Tell the owner what was left out and why; offer to build it.

### 2. Script
- Reel 30–50s with a pain-question hook in the first 2s ("עדיין מנהלים את הפנסיון על לוח מחיק? ביומן גוגל? במחברת?"). Promo ~1:30–2:00.
- One line per scene, everyday spoken Hebrew, no repeated "שלכם"/"אצלכם" ("כל העסק במסך אחד", "ישר ליומן", "נשמר במערכת").
- Write the on-screen headline/subtitle from the narration itself.
- Rephrase known TTS traps up front (see Troubleshooting). Acronyms/URLs as spoken: "איי איי", "פטרה אפ דוט קום".

### 3. Screens (real app, local)
Background general-purpose agent (~10–25 min). Brief: folder `marketing/<name>/shots/`, exact screens + data states, desktop 1600×1000 @2x and mobile 390×844 @3x, JPEG q90, element screenshots `c_*.png` for callouts, "Read every image and redo until polished", cleanup. Prior code: `marketing/*/capture/`. Container setup that works:
- Postgres 16 (`/usr/lib/postgresql/16`), `prisma db push`, `npm run db:seed` **then `npm run db:seed-admin`** (owner@petra.local / Admin1234!), promo seed scripts (business `demo-business-001`), `npm run build && npm start`.
- Playwright Chromium `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`; wait for `.petra-loader-toe` to disappear; JPEG straight from Playwright; crop with ffmpeg `-vf crop=w:h:x:y`.
- Login is rate-limited (vary `x-forwarded-for`); staff users need a `UserConsent` row (else terms screen).
- Read every shot yourself; the agent may re-shoot after you crop — re-crop from the final versions.

### 4. Voice
Needs `OPENAI_API_KEY` + `api.openai.com` allowed (proxy 403 → environment → Edit → Network access; 429 `insufficient_quota` → add credits).
- `python3 voice.py continuous` records the whole script in one take, `split_take()` cuts it at the pauses (whisper word timestamps), `tidy()` trims each clip to the speech (no inhale at the end), each line is transcribed twice, best version per line across the pool wins. Re-run to add takes until all lines are 1.00.
- Borderline winners: re-score the pool candidates with 4 transcriptions and take the best average.
- `words.json` (whisper word timings) drives the subtitles; regenerate it for any replaced clip.

### 5. Music
Gemini prompt template (fill BPM/structure from the script timing):
> Instrumental track, [length], [genre/mood], [BPM], major key. Sits under a Hebrew female voiceover: keep the mid-range clear. **No vocals, no vocal chops, no voice samples, no spoken words, no humming, no choir.** Structure: [intro 0:00–0:04 …], a short full stop/break at [CTA time], clean ending with a final chord by [end].

Then `music_check.py track.mp3`: prints silences (the built-in stop and natural ending), BPM estimate, vocal-stem levels + whisper segments, verdict, and writes `track-instrumental.wav` — always use the instrumental. Align the track's stop to the CTA phrase (said in the silence) and end on the track's final chord (`build.py`: `MUSIC_STOP`, `MUSIC_END`, `CTA_STOP_WORD`). Too short → loop whole bars (crossfade 0.25–0.5s at a bar boundary).

### 6. Build, render, mix
- Scenes = CSS animations frozen by `renderAt(t)`, Playwright screenshots each frame into ffmpeg.
- Reel layout 1080×1920: headline ~y190, media card 960×860 at y470, subtitle pill ~y1390; keep the top ~150px and bottom ~360px free (Instagram UI). Corner logo via `.wm`.
- Pan crops: check the last frame of every pan for empty strips; callouts must not cover subtitles.
- Loudness: measure (`qa_video.py` prints it), adjust the fixed final `volume=` in the mix chain, `build.py remix` (audio only). Promo: `dub.py music` only (no re-render).

### 7. QA before sending
`qa_video.py` transcribes every scene from the final mp4, prints loudness/streams and each clip's edges. Fix anything BAD in both runs (see Troubleshooting), look at stills of every scene, then `SendUserFile` (display `render`), commit + push, and tell the owner exactly what was checked and what is still borderline.

## Troubleshooting (all seen in this project)
| Symptom | Cause | Fix |
|---|---|---|
| Voice sounds robotic / "AI", every sentence starts the same | lines recorded separately | continuous take (`voice.py continuous`) + `NATURAL` prompt |
| "תקיעה של נשימה" at sentence ends | clip ends on the start of the next inhale | `voice.tidy()`; `qa_video.py` flags "after" > 0.15s |
| First word of a clip cut ("הכירו"→"הכי") | trim started inside the word | `tidy()` only trims at ≥40ms of silence; restore and re-tidy |
| Brand garbled ("פטה", "SoftPetra") | "פטרה" at sentence start | put it mid-sentence: "הכירו את פטרה", "בפטרה, …" |
| "שיבוץ"→"שיפוץ", "גוררים"→"בוררים", "וכל"→"בכל" | TTS/transcriber weak spots | rephrase ("בגרירה", "בכל בוקר") |
| A word keeps failing | — | niqqud on that ONE word only (e.g. "לַעֲסָקִים"); full niqqud makes it worse; never strip niqqud to plain text (defective spelling) |
| Clip clean alone, broken in the final mix | music masks it (drum hit or loud section) | delay that line ~0.3s (`EXTRA_LEAD`) if it fits, or lower the constant music gain; move the track's stop under the key phrase; never duck |
| "Someone is talking in the music" | vocal chops in the Gemini track | `music_check.py` → instrumental stem |
| Winner passes QA then fails later | min-of-2 luck | re-score with 4 transcriptions, best average |
| Spelling variants (פטרא, בווטסאפ, ט/ת, ההאכלות) | transcriber noise | ignore |
| Too slow / mispronounced | `gpt-4o-mini-tts` | use `gpt-audio-1.5` |

## Environment gotchas
- Kill stray ffmpeg by PID, never `pkill -f ffmpeg…` (kills your own shell).
- `apad` + `-shortest` with a copied video stream never ends — `apad=whole_dur=` + `-t`.
- `sidechaincompress` stops when its key ends — `apad` the key.
- audio-separator: install CPU torch + torchvision from the PyTorch CPU index (mismatch → `torchvision::nms does not exist`); it needs `ffmpeg` on PATH (the script symlinks `dub.FF`); Demucs models are blocked, UVR models from GitHub work.
- If the auto-mode classifier stalls, put long commands in a script file; commit as soon as access returns.
- Keep big intermediates out of git (`music-bed.wav`, `reel-silent.mp4`, `still_*.png`, previews, `vo/pool/`).

## Promo with the dog as bookends (marketing/promo-video, 2026-10-16, owner: "מושלם")
How the current promo was made; repeat this flow for any promo/explainer.
1. **Voice**: `promo-video/liam_voice.py [scenes]` - Liam, each line read with prev+next as context, up to 8-16 takes; lines with פטרה / איי איי keep the take whose word SOUNDS closest to owner-approved reel takes (`voice_match`), other lines keep the first clean take; then retimes `promo.html` from `orig_starts`. `eleven_voice.spoken()` holds the spoken-only forms (פֶּטרָה, פֶּטִי, per-scene `OVERRIDE`).

Picked this way: "ככה נולדה פטרה" (brand mid-sentence; "בנינו את פטרה." / "הכירו את פטרה," failed 8/8), "סוכן AI" sample 2 of 6, "והפְּנִיּוֹת", "הַתְחִילוּ".
