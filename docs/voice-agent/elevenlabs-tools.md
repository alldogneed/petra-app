# אלירן ← פטרה: מה להגדיר ב-ElevenLabs

מסמך למי שמגדיר את הסוכן בלוח של ElevenLabs. מעודכן ל-21/11/2026. הוא מחליף את חלקים א׳ ו-ג׳ שב-`eliran-system-prompt.md`: אלירן לא קובע שיחות ולא מציע שעות. הוא אוסף פרטים, והנציגה חוזרת ביוזמתה.

**מה מגדירים:** שני כלים (`start_call`, `save_details`) ו-webhook אחד של סוף שיחה. הכלי `book_sales_call` קיים בקוד אבל **לא מוגדר** אצלם.

**כתובת הייצור:** `https://petra-app.com`

## אימות

| מה | איך |
|---|---|
| שני הכלים | כותרת `Authorization` עם הערך `Bearer <הסוד>`. הסוד הוא הערך של `ALLDOG_VOICE_AGENT_SECRET` ב-Vercel. ב-ElevenLabs שומרים אותו כסוד (Secret) ומשתמשים בו רק בכותרת |
| ה-webhook | ElevenLabs חותמת כל בקשה בכותרת `ElevenLabs-Signature`. הסוד של ה-webhook (מתקבל כשיוצרים אותו אצלם) נשמר ב-Vercel כ-`ALLDOG_VOICE_WEBHOOK_SECRET` |

לא לכתוב את ערכי הסודות בפרומפט, בתיאור כלי או בכל מקום שהמודל רואה.

## משתני מערכת (לא מהמודל)

שלושה פרמטרים מגיעים ממשתנים דינמיים של המערכת. בהגדרת הפרמטר בוחרים "Dynamic variable" ולא "LLM prompt", כך שהמודל לא יכול לשנות אותם.

| פרמטר | משתנה | הערה |
|---|---|---|
| `conversationId` | `system__conversation_id` | חובה בשני הכלים |
| `callerPhone` | `system__caller_id` | מספר המתקשר. לוודא בתיעוד של ElevenLabs שזה השם המדויק, ושבמספר חסוי הוא ריק או "anonymous" |
| `externalCallId` | `system__call_id` | אופציונלי, רק ב-`start_call` |

## כלי 1: `start_call`

- **תיאור לכלי:** "נקרא פעם אחת, בתור הראשון שלך בשיחה, לפני שאתה עונה למתקשר. מחזיר אם המתקשר מוכר לנו לפי מספר הטלפון."
- **מתי הוא רץ בפועל:** משפט הפתיחה סטטי, והכלי לא יכול לרוץ במקביל אליו. הוא רץ רק בתור הראשון של המודל, כלומר אחרי שהמתקשר אמר את המשפט הראשון שלו. לכן המתקשר ממתין על הקו בזמן הקריאה, וזמן התגובה של הנתיב הזה קריטי.
- **URL:** `https://petra-app.com/api/webhooks/alldog-voice/start`
- **Method:** `POST`, גוף JSON
- **Headers:** `Authorization: Bearer <הסוד>`, `Content-Type: application/json`
- **זמן המתנה מרבי:** הקצר ביותר שהלוח מאפשר, ולא יותר מ-3 שניות. אם אין תשובה, אלירן ממשיך בלי זיהוי. עדיף שיחה בלי זיהוי על שתיקה בקו.

| פרמטר | סוג | חובה | מקור |
|---|---|---|---|
| `conversationId` | string | כן | משתנה מערכת |
| `callerPhone` | string | לא | משתנה מערכת |
| `externalCallId` | string | לא | משתנה מערכת |

**מה חוזר:**

```json
{
  "known": true,
  "isCustomer": false,
  "firstName": "דנה",
  "dogName": "רקס",
  "city": "כפר סבא",
  "upcomingMeeting": null
}
```

| שדה | משמעות | מה אלירן עושה איתו |
|---|---|---|
| `known` | המספר מוכר (ליד או לקוח) | מותר לפנות בשם הפרטי |
| `isCustomer` | לקוח קיים | לא מוכרים. שואלים במה מדובר ולוקחים הודעה |
| `firstName` | שם פרטי בלבד, או `null` | "היי דנה". זיהוי לפי מספר הוא לא אימות: אם אומרים "זה לא אני", מתנצלים וממשיכים |
| `dogName` | שם הכלב, או `null` | "מתקשרים בקשר לרקס?" |
| `city` | העיר, או `null` | לא לשאול שוב על העיר |
| `upcomingMeeting` | שיחה או פגישה שכבר קבועה (`label` מוכן להקראה), או `null` | מזכירים את המועד |

פטרה לא מחזירה היסטוריה, תשלומים, כתובת, שלב ליד או תקציר וואטסאפ.

## כלי 2: `save_details`

- **תיאור לכלי:** "שומר את הפרטים שנאספו בשיחה ופותח לנציגה משימה לחזור ללקוח. נקרא פעם אחת, לקראת סוף השיחה, אחרי שנאספו הפרטים. במקרה דחוף (נשיכה של אדם, סכנה לילד) נקרא מיד כשזה מתברר, עם urgent=true."
- **URL:** `https://petra-app.com/api/webhooks/alldog-voice/details`
- **Method:** `POST`, גוף JSON
- **Headers:** `Authorization: Bearer <הסוד>`, `Content-Type: application/json`
- **משפט המתנה לפני הקריאה:** אין. הכלי נקרא בלי הודעה למתקשר.
- **זמן המתנה מרבי:** 10 שניות.

**כל שדה חוץ מ-`conversationId` יכול להיות חסר.** שדה שלא נאמר בשיחה לא שולחים, או שולחים ריק. שמירה לא נכשלת בגלל שדה חסר.

| פרמטר | סוג | חובה | מקור | תיאור לפרמטר |
|---|---|---|---|---|
| `conversationId` | string | כן | משתנה מערכת | |
| `callerPhone` | string | לא | משתנה מערכת | |
| `callbackPhone` | string | לא | המודל | "מספר לחזרה שהמתקשר אמר בקול, רק כשהמספר שלו חסוי, ורק אחרי שהוקרא לו ספרה-ספרה והוא אישר" |
| `fullName` | string | לא | המודל | "שם המתקשר כפי שאמר" |
| `city` | string | לא | המודל | "העיר שבה הוא גר" |
| `dogName` | string | לא | המודל | "שם הכלב" |
| `breed` | string | לא | המודל | "גזע הכלב" |
| `age` | string | לא | המודל | "גיל הכלב, במילים של המתקשר" |
| `problem` | string | לא | המודל | "תיאור הבעיה במשפט אחד, במילים של המתקשר" |
| `urgent` | boolean | לא | המודל | "true רק כשאדם ננשך או הותקף, כשיש סכנה לילד או לתינוק, או כששוקלים למסור את הכלב" |
| `urgentReason` | string | לא | המודל | "מה קרה, במילים של המתקשר. רק כש-urgent" |
| `eventWhen` | string | לא | המודל | "מתי קרה האירוע הדחוף: 'אתמול בערב', 'לפני שבוע'. רק כש-urgent" |

"האם לקוח קיים" לא נשלח: פטרה קובעת זאת בעצמה לפי המספר.

**מה חוזר ומה אלירן אומר:**

| תשובה | מתי | מה אלירן עושה |
|---|---|---|
| `{"status":"saved"}` | נשמר | משפט הסיום: "הפרטים אצלי, ורחלי תחזור אליכם תוך כחצי שעה, בשעות הפעילות." |
| `{"status":"phone_required"}` | המספר חסוי ולא נשלח `callbackPhone` | מבקש מספר לחזרה, מקריא אותו ספרה-ספרה, ואחרי אישור קורא שוב לכלי עם `callbackPhone` |
| שגיאה (401, 400, 500) או אין תשובה בזמן | תקלה | אותו משפט סיום. לא קורא שוב. הפרטים יגיעו לפטרה בכל מקרה מהתמליל של סוף השיחה |

**מה קורה בפטרה אחרי `saved`:**
- ליד נוצר, או מתעדכן אם המספר כבר קיים. ממלאים רק שדות ריקים.
- נפתחת משימת "לחזור טלפונית" אחת, עם יעד: 30 דקות מרגע השיחה בשעות הפעילות, ומחוץ להן בפתיחת יום הפעילות הבא. זה מה שמשפט הסיום מבטיח. (שעות הפעילות בקוד כרגע: ראשון עד חמישי 9:00–17:00, שישי 9:00–14:00. הן ממתינות לאישור של אור, כי בהגדרות העסק בפטרה רשום אחרת.)
- מקרה דחוף: המשימה מסומנת דחופה, והנציגה ואור מקבלים התראה מיד.

## Webhook של סוף שיחה

- **סוג:** Post-call webhook, האירוע `post_call_transcription`.
- **URL:** `https://petra-app.com/api/webhooks/alldog-voice/end`
- **חתימה:** מופעלת (HMAC). הסוד נשמר ב-Vercel כ-`ALLDOG_VOICE_WEBHOOK_SECRET`.
- **ניסיונות חוזרים (Retries):** להפעיל.
- **שליחת שמע (Send audio):** לכבות.

**מה קורה בפטרה:** התמליל נשמר, ו-Claude כותב סיכום ליומן הליד, באותו מבנה של סיכום שיחת הוואטסאפ ותחת הכותרת `[שיחת טלפון · אלירן]`. הנציגה מקבלת פעמון ווואטסאפ עם שורת הסיכום. זה קורה תמיד, גם כש-`save_details` לא נקרא: אז הליד והמשימה נוצרים מהתמליל.

**שיחה ממספר חסוי בלי מספר לחזרה:** לא נוצר ליד, אבל הנציגה ואור מקבלים התראה עם הסיכום.

## מה לשנות בפרומפט של הסוכן

- למחוק את ההערה הזמנית שאוסרת להפעיל כלים.
- `start_call` נקרא בתור הראשון של המודל, לפני התשובה הראשונה למתקשר. משפט הפתיחה הסטטי לא משתנה.
- `save_details` נקרא פעם אחת לקראת סוף השיחה, בלי משפט המתנה, ואחריו משפט הסיום. במקרה דחוף: מיד.
- מספר חסוי: לבקש מספר לחזרה מוקדם בשיחה, להקריא ספרה-ספרה ולקבל אישור.
- לא להקריא למתקשר שום דבר מעבר לשם הפרטי, שם הכלב והעיר.

## בדיקות אחרי ההגדרה

| # | מה עושים | מה מצפים לראות בפטרה |
|---|---|---|
| 1 | שיחה רגילה ממספר חדש, עם כל הפרטים | ליד חדש, משימה עם יעד, שורת סיכום ביומן, פעמון ווואטסאפ לנציגה תוך דקה או שתיים |
| 2 | שיחה נוספת מאותו מספר | אותו ליד, אותה משימה, שורת סיכום נוספת |
| 3 | שיחה ממספר חסוי, עם מספר לחזרה | ליד תחת המספר שנאמר |
| 4 | שיחה דחופה ("הכלב נשך את הבן") | משימה דחופה, והתראה מיידית לנציגה ולאור |
| 5 | ניתוק באמצע, לפני `save_details` | ליד ומשימה נוצרים מהתמליל |
| 6 | בלוג של Vercel: השורה `[paycall voice-agent]` | מה PayCall מדווח כיעד השיחה (`callee`). לפי זה מחליטים אם להפעיל את `ALLDOG_VOICE_PAYCALL_FILTER_ENABLED` |
